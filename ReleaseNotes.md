## Tag 1.0.55

### Изменения


- добавлен дополнительный параметр в замыкание, которое срабатывает при загрузке виджета. Параметр принимает значение true в случае ошибки загрузки виджета. 
- добавлена возможность выбора первой фото из альбома для отображенеия виджета, если виджет опубликован без фото.
